Главная и поперечная оси в флекс блоках в CSS

Про флексбоксы можно говорить в двух терминах: первое это - ряд или колонка, второе - в терминах осей. С рядами и колонками мы уже разобрались, давайте теперь разберемся с осями. Понимание осей нужно для того, чтобы выравнивать элементы по горизонтали или по вертикали.

При работе с флекс элементами всегда существует главная ось и поперечная. Мы можем элементы выравнивать по главной оси и поперек главной оси. Главная ось может иметь 4 направления: слева направо, справа налево, сверху вниз и снизу вверх.

Направление поперечной оси зависит от направления главной: если главная ось горизонтальна, то поперечная направлена сверху вниз, если главная ось вертикальна, то поперечная направлена слева направо. Других направлений поперечная ось иметь не может.

Направление главной оси регулируется свойством flex-direction. Если данное свойство имеет значение row - главная ось направлена слева направо, если же значение row-reverse, то справа налево. Значение column направляет ось сверху вниз, а значение column-reverse - снизу вверх.

Вопросы

  1. Пусть главная ось горизонтальна. Куда будет направлена поперечная ось?

    Поперечная ось будет направлена вертикально.

  2. Пусть главная ось вертикальна. Куда будет направлена поперечная ось?

    Поперечная ось будет направлена горизонтально.

  3. Пусть поперечная ось направлена направо. Куда в таком случае может быть направлена главная ось?

    Если поперечная ось горизонтальна (то есть направлена слева направо - это её стандартное направление), то главная ось вертикальна - то есть сверху вниз (или снизу вверх, если column-reverse)

  4. Пусть поперечная ось направлена вниз. Куда в таком случае может быть направлена главная ось?

    Главная ось будет направлена слева направо.

  5. Может ли поперечная ось быть направлена справа налево?

    Нет, поперечная ось не может быть направлена справа налево. Она всегда направлена слева направо (если горизонтальна) или сверху вниз (если вертикальна).

  6. Может ли поперечная ось быть направлена снизу вверх?

    Нет, поперечная ось не может быть направлена снизу вверх. Если она вертикальна - всегда направлена сверху вниз.

  7. Пусть свойство flex-direction имеет значение row. Куда будет направлена главная ось? Куда будет направлена поперечная ось?

    Главная ось будет направлена слева направо, а поперечная ось будет направлена сверху вниз.

  8. Пусть свойство flex-direction имеет значение column. Куда будет направлена главная ось? Куда будет направлена поперечная ось?

    Главная ось будет направлена сверху вниз, а поперечная ось будет направлена слева направо.

  9. Пусть свойство flex-direction имеет значение row-reverse. Куда будет направлена главная ось? Куда будет направлена поперечная ось?

    Главная ось будет направлена справа налево, а поперечная ось будет направлена сверху вниз.

  10. Пусть свойство flex-direction имеет значение column-reverse. Куда будет направлена главная ось? Куда будет направлена поперечная ось?

    Главная ось будет направлена снизу вверх, а поперечная ось будет направлена слева направо.
